I. OVERVIEW SISTEM
═══════════════════════════════════════════════════════════════════════════════════

Nama Sistem        : STAFFLINK
Tipe               : Desktop Application (Java Swing + MySQL)
Bahasa Program     : Java
Database           : MySQL (Database: pbol)
Arsitektur         : MVC (Model-View-Controller)
Framework UI       : Java Swing

Fungsi Utama:
✓ Manajemen user (login & registrasi dengan role-based)
✓ Manajemen data karyawan (CRUD)
✓ Tracking absensi real-time (check-in/check-out)
✓ Pengajuan dan persetujuan cuti
✓ Perhitungan dan slip gaji otomatis

│ • Check-out: ID Karyawan (from session), Waktu (auto)                      │
│ • Laporan: Filter tanggal (opsional)                                       │
│                                                                              │
│ OUTPUT:                                                                      │
│ • Konfirmasi check-in/check-out                                             │
│ • Laporan absensi (tabel/PDF)                                               │
│ • Statistik kehadiran                                                       │

┌─────────────────────────────────────────────────────────────────────────────┐
│ PROSES P5: MANAJEMEN PENGGAJIAN (HRD)                                       │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                              │
│ DESKRIPSI:                                                                   │
│ HRD menginput data gaji setiap bulan, sistem otomatis menghitung            │
│ gaji bersih, dan menghasilkan slip gaji per karyawan.                       │
│                                                                              │
│ FLOW - INPUT DATA GAJI (HRD):                                               │
│ 1. HRD login & masuk HRDDashboard.java                                      │
│ 2. Menu: "Hitung Gaji Karyawan"                                             │
│ 3. Form tampil: FormHitungGaji.java                                         │
│ 4. Input data gaji (P5.1):                                                  │
│    - Pilih Karyawan (Dropdown dari D2:karyawan)                             │
│    - Gaji Pokok (Gapok)                                                     │
│    - Jam Lembur                                                             │
│    - Upah Lembur Per Jam                                                    │
│    - Potongan (Pajak, Cicilan, dsb)                                        │
│    - Periode (Bulan & Tahun)                                                │
│ 5. Validasi form: Semua field harus terisi dan numerik                     │
│ 6. Jika valid: Proses perhitungan gaji (P5.2)                              │
│                                                                              │
│ FLOW - HITUNG GAJI OTOMATIS:                                                │
│ Formula:                                                                     │
│    Gaji Bruto = Gapok + (Jam Lembur × Upah Lembur Per Jam)                │
│    Gaji Bersih = Gaji Bruto - Potongan                                     │
│                                                                              │
│ Example:                                                                     │
│    Gapok = 5.000.000                                                        │
│    Jam Lembur = 10 jam                                                      │
│    Upah Per Jam = 150.000                                                   │
│    Potongan = 500.000                                                       │
│                                                                              │
│    Gaji Bruto = 5.000.000 + (10 × 150.000) = 6.500.000                    │
│    Gaji Bersih = 6.500.000 - 500.000 = 6.000.000                          │
│                                                                              │
│ FLOW - SIMPAN GAJI KE DATABASE:                                             │
│ 1. INSERT ke D5:gaji (P5.3):                                               │
│    (id_karyawan, gapok, jam_lembur, upah_lembur_per_jam,                  │
│     potongan, gaji_bersih, bulan, tahun, created_at)                      │
│ 2. Sistem cek: Apakah sudah ada record gaji bulan ini?                     │
│    - Jika sudah ada: UPDATE daripada INSERT                                │
│    - Jika belum ada: INSERT baru                                            │
│ 3. Success message tampil                                                   │
│                                                                              │
│ FLOW - GENERATE SLIP GAJI:                                                  │
│ 1. HRD buka "Generate Slip Gaji" atau otomatis setelah simpan gaji         │
│ 2. Sistem query D5:gaji + JOIN D2:karyawan + JOIN D3:absensi (optional)   │
│ 3. Format slip gaji (P5.4):                                                 │
│    ┌──────────────────────────────┐                                        │
│    │     SLIP GAJI KARYAWAN        │                                        │
│    ├──────────────────────────────┤                                        │
│    │ Nama: [Nama Karyawan]         │                                        │
│    │ ID: [ID Karyawan]             │                                        │
│    │ Jabatan: [Jabatan]            │                                        │
│    │ Periode: [Bulan/Tahun]        │                                        │
│    │                               │                                        │
│    │ RINCIAN GAJI:                 │                                        │
│    │ Gaji Pokok: [Gapok]           │                                        │
│    │ Tunjangan Lembur: [TunLembur] │                                        │
│    │ Potongan: [Potongan]          │                                        │
│    │ ─────────────────────         │                                        │
│    │ GAJI BERSIH: [GajiBersih]     │                                        │
│    │                               │                                        │
│    │ TTD HRD: _________            │                                        │
│    │ TTD Karyawan: _________       │                                        │
│    └──────────────────────────────┘                                        │
│ 4. Output: PDF atau Print langsung                                          │
│                                                                              │
│ FLOW - LAPORAN PENGGAJIAN BULANAN:                                          │
│ 1. HRD buka "Laporan Penggajian"                                            │
│ 2. Input filter: Bulan & Tahun                                              │
│ 3. Sistem query D5:gaji WHERE bulan=X AND tahun=Y + JOIN D2:karyawan      │
│ 4. Tampilkan tabel:                                                         │
│    No │ Nama Karyawan │ Gapok │ Lembur │ Potongan │ Gaji Bersih           │
│    ─────────────────────────────────────────────────────────────────       │
│    1  │ [Nama]        │ [val] │ [val]  │ [val]    │ [val]                 │
│    2  │ [Nama]        │ [val] │ [val]  │ [val]    │ [val]                 │
│    ...                                                                      │
│    TOTAL PENGGAJIAN BULAN [X]: [Rp Total]                                  │
│                                                                              │
│ 5. Bisa di-export ke PDF atau Excel                                        │
│                                                                              │
│ FLOW - KARYAWAN LIHAT SLIP GAJI:                                            │
│ 1. Karyawan login & masuk KaryawanDashboard                                 │
│ 2. Menu: "Slip Gaji" atau "Gaji Saya"                                      │
│ 3. Sistem query D5:gaji WHERE id_karyawan=[ID] ORDER BY created_at DESC   │
│ 4. Tampilkan daftar slip gaji (bulanan):                                   │
│    [2025-12 Slip Gaji Desember] [LIHAT] [PRINT] [DOWNLOAD]                │
│    [2025-11 Slip Gaji November] [LIHAT] [PRINT] [DOWNLOAD]                │
│    ...                                                                      │
│ 5. Karyawan klik [LIHAT] untuk melihat detail slip                         │
│                                                                              │
│ INPUT:                                                                       │
│ • Karyawan (Pilih dari dropdown)                                            │
│ • Gapok, Jam Lembur, Upah Lembur/Jam, Potongan                             │

IV. DATA STORES (DATABASE SCHEMA)
═══════════════════════════════════════════════════════════════════════════════════

D1: TABLE user
───────────────────────────────────────────────────────────────
id              VARCHAR(50)  PRIMARY KEY (USR001, USR002, ...)
email           VARCHAR(100) UNIQUE
password        VARCHAR(255) (Hashed)
role            ENUM('K', 'A', 'H')  - Karyawan, Admin, HRD
id_karyawan     VARCHAR(50)  FOREIGN KEY → karyawan.id
created_at      TIMESTAMP    DEFAULT CURRENT_TIMESTAMP
───────────────────────────────────────────────────────────────

D2: TABLE karyawan
───────────────────────────────────────────────────────────────
id              VARCHAR(50)  PRIMARY KEY (K001, K002, ...)
nama            VARCHAR(100)
jabatan         VARCHAR(50)  - Contoh: Admin, HRD, Karyawan
no_hp           VARCHAR(20)
no_rekening     VARCHAR(50)
created_at      TIMESTAMP    DEFAULT CURRENT_TIMESTAMP
updated_at      TIMESTAMP    DEFAULT CURRENT_TIMESTAMP ON UPDATE
───────────────────────────────────────────────────────────────

D3: TABLE absensi
───────────────────────────────────────────────────────────────
id              INT          PRIMARY KEY AUTO_INCREMENT
id_karyawan     VARCHAR(50)  FOREIGN KEY → karyawan.id
tanggal         DATE
jam_masuk       TIME         (Check-in time)
jam_pulang      TIME         (Check-out time)
status          ENUM('Hadir', 'Izin', 'Sakit', 'Alpha')
created_at      TIMESTAMP    DEFAULT CURRENT_TIMESTAMP
───────────────────────────────────────────────────────────────

D4: TABLE cuti
───────────────────────────────────────────────────────────────
id              INT          PRIMARY KEY AUTO_INCREMENT
id_karyawan     VARCHAR(50)  FOREIGN KEY → karyawan.id
tanggal_mulai   DATE
tanggal_selesai DATE
keterangan      TEXT         (Alasan cuti)
status          ENUM('Pending', 'Disetujui', 'Ditolak')
created_at      TIMESTAMP    DEFAULT CURRENT_TIMESTAMP
updated_at      TIMESTAMP    DEFAULT CURRENT_TIMESTAMP ON UPDATE
───────────────────────────────────────────────────────────────

D5: TABLE gaji
───────────────────────────────────────────────────────────────
id                  INT          PRIMARY KEY AUTO_INCREMENT
id_karyawan         VARCHAR(50)  FOREIGN KEY → karyawan.id
gapok               INT          (Gaji Pokok)
jam_lembur          INT
upah_lembur_per_jam INT
potongan            INT
gaji_bersih         INT          (CALCULATED: Bruto - Potongan)
bulan               VARCHAR(10)  (Format: "01" - "12")
tahun               VARCHAR(4)   (Format: "2025")
created_at          TIMESTAMP    DEFAULT CURRENT_TIMESTAMP
───────────────────────────────────────────────────────────────

V. ALUR TRANSAKSI HARIAN SISTEM
═══════════════════════════════════════════════════════════════════════════════════

PAGI (09:00 AM):
────────────────
User (Karyawan) →
  Login (P1) →
    Query D1:user, verify password →
    Set session (UserSession) →
    Redirect KaryawanDashboard →
  Click [CHECK-IN] (P3.1) →
    Query D3:absensi (cek record hari ini) →
    No record found → INSERT baru →
    jam_masuk = 09:00 →
    Success: "Check-in berhasil pukul 09:00"


SORE (17:00 PM):
────────────────
User (Karyawan) →
  Click [CHECK-OUT] (P3.2) →
    Query D3:absensi (cari record hari ini) →
    Record found → UPDATE jam_pulang = 17:00 →
    Success: "Check-out berhasil pukul 17:00"


KAPAN SAJA (Cuti):
──────────────────
User (Karyawan) →
  Click [AJUKAN CUTI] (P4.1) →
    Input: tgl_mulai, tgl_selesai, alasan →
    Validasi form →
    INSERT D4:cuti (status='Pending') →
    Notifikasi ke HRD →
    "Pengajuan terkirim"

                    ⏳ WAITING ⏳

User (HRD/Admin) →
  View [REVIEW CUTI] (P4.3) →
    Query D4:cuti (WHERE status='Pending') →
    Tampilkan list →
  Click [SETUJUI] atau [TOLAK] (P4.4) →
    UPDATE D4:cuti (status='Disetujui' / 'Ditolak') →
    Notifikasi ke Karyawan →
    "Cuti [Disetujui/Ditolak]"


AKHIR BULAN (HRD):
──────────────────
User (HRD) →
  Click [HITUNG GAJI] (P5.1) →
    Form input: Karyawan, gapok, lembur, potongan, bulan, tahun →
    Validasi form →
  Click [HITUNG] (P5.2) →
    Calculate: Gaji Bruto = gapok + (jam_lembur × upah/jam) →
    Gaji Bersih = Gaji Bruto - Potongan →
    Tampilkan hasil perhitungan →
  Click [SIMPAN] (P5.3) →
    INSERT/UPDATE D5:gaji →
    Success: "Gaji tersimpan"
  
  Click [GENERATE SLIP] (P5.4) →
    Query D5:gaji + JOIN D2:karyawan →
    Format PDF slip gaji →
    Bisa [PRINT] / [DOWNLOAD] →
    Slip gaji siap tanda tangan


ANYTIME (Karyawan Lihat Slip):
───────────────────────────────
User (Karyawan) →
  Click [SLIP GAJI] (P5) →
    Query D5:gaji (WHERE id_karyawan = session) →
    List slip gaji bulanan →
  Click [LIHAT] →
    View detail slip gaji →
  Click [PRINT] →
    Print slip gaji

VIII. FITUR KEAMANAN SISTEM
═══════════════════════════════════════════════════════════════════════════════════

✓ AUTHENTICATION:
  - Login dengan email & password
  - Password hashing (tidak disimpan plaintext)
  - Role-based access control (RBAC): Karyawan, Admin, HRD

✓ AUTHORIZATION:
  - Setiap form/menu hanya accessible sesuai role
  - Admin hanya bisa akses admin features
  - Karyawan hanya bisa lihat data pribadi
  - HRD hanya bisa akses payroll functions

✓ SESSION MANAGEMENT:
  - UserSession tracking (ID, Role, Nama, Jabatan)
  - Session invalidation saat logout
  - Single session per user (prevent duplicate login)

✓ DATA VALIDATION:
  - Form validation (input tidak kosong, format valid)
  - Database constraint (UNIQUE email, FOREIGN KEY)
  - Date validation (tanggal harus logis)

✓ AUDIT TRAIL:
  - created_at & updated_at timestamps
  - Track kapan data dibuat/diubah


═══════════════════════════════════════════════════════════════════════════════════

IX. PERFORMA & OPTIMASI
═══════════════════════════════════════════════════════════════════════════════════

✓ DATABASE INDEXING:
  - PRIMARY KEY pada id karyawan, user, dll
  - FOREIGN KEY indexed untuk JOIN optimization
  - Unique index pada email (untuk login cepat)

✓ QUERY OPTIMIZATION:
  - SELECT hanya field yang diperlukan (bukan SELECT *)
  - WHERE clause untuk filter yang tepat
  - JOIN efficient untuk laporan

✓ CACHING:
  - Session caching (reduce repeated login queries)
  - Dropdown values cached (karyawan list, jabatan)

✓ PAGINATION:
  - Laporan besar di-paginate (per 50/100 baris)
  - Mencegah memory overflow

✓ CONNECTION POOLING:
  - Database connection management
  - koneksi.getKoneksi() reuse existing connection


═══════════════════════════════════════════════════════════════════════════════════

X. KESIMPULAN
═══════════════════════════════════════════════════════════════════════════════════

STAFFLINK adalah sistem terintegrasi yang dirancang untuk mengelola seluruh
proses HR di suatu organisasi, mulai dari:

1. AUTHENTICATION → Kontrol akses dengan role-based system
2. EMPLOYEE MGMT → CRUD data karyawan oleh Admin
3. ATTENDANCE → Real-time tracking kehadiran karyawan
4. LEAVE MGMT → Pengajuan dan approval cuti
5. PAYROLL → Perhitungan gaji otomatis dan slip

Sistem menggunakan:
- Backend: Java dengan MVC architecture
- Frontend: Java Swing GUI (Desktop)
- Database: MySQL (pbol)
- Komunikasi: JDBC (Java Database Connectivity)

Dengan 5 data stores (user, karyawan, absensi, cuti, gaji), 5 proses utama (P1-P5),
dan 3 role berbeda (Karyawan, Admin, HRD), STAFFLINK menyediakan solusi lengkap
untuk manajemen SDM modern.
