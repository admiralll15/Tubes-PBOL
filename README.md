## Deskripsi Proyek
Repository ini berisi Tugas Besar mata kuliah **Pemrograman Berorientasi Objek Lanjutan (PBOL)**.
Aplikasi ini dikembangkan untuk memenuhi kebutuhan tugas akhir mata kuliah dengan menerapkan konsep
Object-Oriented Programming (OOP) seperti enkapsulasi, pewarisan, polimorfisme, dan abstraksi.

## Fitur Aplikasi
1. Manajemen Data Karyawan
 Sistem dapat melakukan input, penyimpanan, dan pengelolaan data karyawan (ID, 
nama, jabatan, dan gaji pokok).
2. Absensi Karyawan
 Sistem menyediakan form untuk mencatat kehadiran harian karyawan (jam masuk 
dan jam pulang).
 Sistem mencatat izin atau cuti karyawan secara sederhana. 
3. Penggajian
 Sistem menghitung gaji karyawan berdasarkan data absensi, lembur, dan potongan.
 Sistem menghasilkan data total gaji setiap karyawan dalam periode tertentu.
4. Laporan
 Sistem dapat menampilkan laporan absensi dan penggajian secara terstruktur.
 Laporan dapat digunakan pihak manajemen untuk evaluasi bulanan dan diunduh dengan pdf.
5. Otentikasi Pengguna
 Sistem menyediakan fitur login untuk admin, HRD, dan karyawan agar data lebih 
terjaga dan terkontrol.

## Teknologi yang Digunakan
- Bahasa Pemrograman: Java  
- Tools/IDE: NetBeans
- Database: MySQL

## Cara Menjalankan Program
1. Clone repository ini:
   git clone https://github.com/admiralll15/Tubes-PBOL.git
   
   Atau download manual melalui GitHub (Code → Download ZIP), lalu extract.

2. Membuka Project di NetBeans

- Buka NetBeans IDE
- Pilih menu File → Open Project
- Arahkan ke folder Tubes-PBOL
- Klik Open Project
- NetBeans akan otomatis mengenali project Java (Ant).

3. Konfigurasi Database

Jalankan MySQL / XAMPP / LARAGON
Buat database sesuai aplikasi (pbol.sql)
Import file database (jika tersedia)

4. Menjalankan Aplikasi

Klik kanan project → Run
