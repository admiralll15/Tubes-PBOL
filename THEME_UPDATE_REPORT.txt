🚀 MAINTAINING THE THEME
═════════════════════════════════════════════════════════════════════════════

When adding new forms or components:

1. Always use GUITemplate methods:
   - GUITemplate.createButton()
   - GUITemplate.createTextField()
   - GUITemplate.createHeaderPanel()

2. Use the color constants:
   - GUITemplate.PRIMARY
   - GUITemplate.SUCCESS_GREEN
   - GUITemplate.ERROR_RED

3. Apply gradients for backgrounds:
   - Use BG_GRADIENT_START and BG_GRADIENT_END
   - Override paintComponent() for custom rendering

4. Font sizes:
   - FONT_TITLE (28px) for main titles
   - FONT_HEADING_BOLD (20px) for section headers
   - FONT_LABEL_BOLD (14px) for labels
   - FONT_BODY_REGULAR (13px) for regular text
